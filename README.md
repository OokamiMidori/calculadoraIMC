# calculadoraIMC
Descubra o seu IMC de forma simples e rápida!
Nosso site foi desenvolvido para ajudá-lo a calcular o Índice de Massa Corporal (IMC), fornecendo informações valiosas sobre sua saúde e bem-estar.
Basta inserir os seus dados e, em segundos, você terá uma análise personalizada para entender melhor sua condição física.
Comece hoje a cuidar da sua saúde!
