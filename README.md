# Calculadora de IMC
Este projeto permite calcular o Índice de Massa Corporal (IMC) de forma intuitiva, utilizando apenas HTML, CSS e JavaScript.
Sem necessidade de instalações complicadas, basta baixar os arquivos e abrir no navegador!

## 🔗 Acesse o site online
Seu site está disponível no GitHub Pages. Acesse diretamente pelo link:

➡️ https://ookamimidori.github.io/calculadoraIMC/

## 🔗 Como baixar e testar o site
1. Clone o repositório
Abra o terminal e execute:
git clone [URL_DO_REPOSITORIO]


Substitua [URL_DO_REPOSITORIO] pelo link do seu repositório no GitHub.

2. Acesse a pasta do projeto
cd nome-do-projeto

Substitua nome-do-projeto pelo nome correto da pasta clonada.

3. Abra o arquivo no navegador
Não é necessário configurar servidores ou instalar dependências! Basta seguir uma das opções:
- Opção 1: Clique duas vezes no arquivo index.html e abra diretamente no navegador.
- Opção 2: Arraste o arquivo index.html para uma nova aba do navegador.
- Opção 3: Se preferir testar em um ambiente local com servidor simples, use o seguinte comando no terminal:npx http-server .
- # Necessário ter Node.js instalado
Em seguida, acesse http://localhost:8080.
